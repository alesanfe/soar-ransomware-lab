Documentación: API de Objetos Guardados de Kibana

Plataforma de visualización y dashboard para Elasticsearch. Kibana proporciona APIs para gestionar objetos guardados, dashboards y visualizaciones.

Conceptos y Casos de Uso

Kibana es una plataforma de visualización y exploración de datos que trabaja con Elasticsearch para proporcionar potentes capacidades de análisis de datos:

  • Objetos Guardados: Objetos de Kibana que pueden guardarse y compartirse (dashboards, visualizaciones, patrones de índice, mapas, etc.). Estos se almacenan en Elasticsearch.
  • Espacios: Espacios de trabajo lógicos que permiten a múltiples equipos usar la misma instancia de Kibana con contenido y permisos aislados.
  • Búsqueda: APIs para consultar datos de Elasticsearch con soporte para KQL (Kibana Query Language) y sintaxis de consultas Lucene.
  • APIs Core: APIs de nivel de sistema para verificar el estado, capacidades y configuración de Kibana.
  • Integración con Elasticsearch: Kibana usa Elasticsearch como su almacén de datos. Todos los objetos guardados y patrones de índice se almacenan en índices de Elasticsearch.

Buscar objetos guardados

DELETE /saved_objects/{type}/{id}

Eliminar objeto guardado

Obtener objetos guardados en masa
