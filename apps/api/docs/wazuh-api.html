API de Wazuh

Contenedor: soar_wazuh
Puerto: 55000
URL Base: http://localhost:55000/api
Documentación: Documentación de la API de Wazuh

Plataforma de gestión de información y eventos de seguridad. Wazuh proporciona una API RESTful para gestionar agentes, eventos de seguridad y respuesta activa.

Conceptos y Casos de Uso

Wazuh es una plataforma de gestión de información y eventos de seguridad (SIEM) que proporciona detección de amenazas, respuesta a incidentes y monitoreo de cumplimiento:

  • Agentes: Software instalado en endpoints (servidores, estaciones de trabajo, contenedores) que monitorea la actividad del sistema y envía logs al servidor Wazuh.
  • Grupos: Agrupaciones lógicas de agentes para aplicar configuraciones, reglas y políticas en múltiples sistemas.
  • Decodificadores: Reglas que analizan mensajes de log en datos estructurados para su análisis. Los decodificadores extraen campos relevantes de los logs sin procesar.
  • Reglas: Lógica de detección que identifica patrones sospechosos en los datos de log. Las reglas generan alertas cuando se cumplen las condiciones.
  • Listas: Archivos CDB (base de datos CDB) para mantener listas negras de IPs, listas blancas y otros datos de referencia utilizados en la evaluación de reglas.
  • Respuesta Activa: Acciones automatizadas activadas por eventos de seguridad (ej. bloquear IPs, terminar procesos, aislar hosts).

Autenticación

Wazuh utiliza autenticación basada en tokens JWT. Inicie sesión para obtener un token, luego inclúyalo en el encabezado de Authorization.

Encabezado de Authorization: Authorization: Bearer {jwt_token}

Ejemplos de Pruebas

Usando curl

# Iniciar Sesión
curl -X POST http://localhost:55000/api/security/user/authenticate \
  -H "Content-Type: application/json" \
  -d '{"username":"wazuh-wui","password":"password"}'

# Listar Agentes
curl -X GET http://localhost:55000/api/agents \
  -H "Authorization: Bearer {jwt_token}"

Usando Python

import requests

# Iniciar Sesión
response = requests.post("http://localhost:55000/api/security/user/authenticate",
    json={"username":"wazuh-wui","password":"password"})
token = response.json()["data"]["token"]

# Listar Agentes
headers = {"Authorization": f"Bearer {token}"}
response = requests.get("http://localhost:55000/api/agents", headers=headers)
print(response.json())
