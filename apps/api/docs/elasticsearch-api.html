API de Elasticsearch

Contenedor: soar_elasticsearch
Puerto: 19200

Documentación: API REST de Elasticsearch

Motor de búsqueda y análisis distribuido. Elasticsearch proporciona una API RESTful para indexar, buscar y gestionar datos.

Conceptos y Casos de Uso

Elasticsearch es un motor de búsqueda y análisis distribuido y RESTful capaz de abordar un creciente número de casos de uso:

  • Clúster: Una colección de uno o más nodos que juntos contienen todos sus datos y proporcionan capacidades de indexación y búsqueda federadas en todos los nodos.
  • Índice: Una colección de documentos con características similares. Un índice es la unidad de nivel más alto en Elasticsearch (como una base de datos en SQL).
  • Documento: Una unidad de información que puede indexarse (como una fila en SQL). Los documentos son objetos JSON.
  • Búsqueda: Capacidades de búsqueda de texto completo con soporte para consultas complejas, agregaciones y filtros.
  • Agregaciones: Capacidades de análisis de datos para resumir y analizar datos (métricas, buckets, etc.).
  • Operaciones Masivas: Indexar o eliminar eficientemente múltiples documentos en una sola solicitud.

Autenticación

Elasticsearch utiliza autenticación básica con nombre de usuario y contraseña.

Credenciales por defecto: elastic / {ELASTIC_PASSWORD}

Clúster

GET /_cluster/health

Obtener salud del clúster

GET /_cluster/state

Obtener estado del clúster

GET /_cluster/stats

Obtener estadísticas del clúster

GET /_cluster/settings

Obtener configuración del clúster

PUT /_cluster/settings

Actualizar configuración del clúster

Operaciones de Índice

PUT /{index}

Crear índice

GET /{index}

Obtener información del índice

DELETE /{index}

Eliminar índice

GET /_cat/indices

Listar todos los índices

GET /{index}/_mapping

Obtener mapping del índice

PUT /{index}/_mapping

Actualizar mapping del índice

GET /{index}/_settings

Obtener configuración del índice

Operaciones de Documento

POST /{index}/_doc

Indexar un documento

PUT /{index}/_doc/{id}

Indexar documento con ID

GET /{index}/_doc/{id}

Obtener documento

POST /{index}/_update/{id}

Actualizar documento

DELETE /{index}/_doc/{id}

Eliminar documento

POST /{index}/_bulk

Operaciones masivas

Búsqueda

GET /{index}/_search

Buscar documentos

POST /{index}/_search

Buscar con query DSL

GET /_search

Buscar en todos los índices

GET /{index}/_count

Contar documentos

GET /{index}/_explain/{id}

Explicar puntuación

Agregaciones

GET /{index}/_search

Agregaciones en búsqueda

Tipos de agregación: terms, avg, sum, min, max, stats, date_histogram, range

GET /_cat/nodes?v

GET /_cat/health?v

Ejemplos de Pruebas

Usando curl

# Salud del Clúster
curl -X GET http://localhost:9201/_cluster/health

# Indexar Documento
curl -X POST http://localhost:9201/test-index/_doc \
  -H "Content-Type: application/json" \
  -d '{"field":"value"}'

Usando Python

from elasticsearch import Elasticsearch

es = Elasticsearch(['http://localhost:9201'])

# Salud del Clúster
print(es.cluster.health())

# Indexar Documento
es.index(index='test-index', document={'field': 'value'})
