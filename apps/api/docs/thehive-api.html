API de TheHive

Contenedor: soar_thehive
Puerto: 9000
URL Base: http://localhost:9000/api
Documentación: Documentación de la API de TheHive

Plataforma colaborativa de gestión de casos para respuesta a incidentes. TheHive proporciona una API RESTful para gestionar casos, observables, tareas y alertas.

Conceptos y Casos de Uso

TheHive es una plataforma colaborativa de respuesta a incidentes que ayuda a los equipos de seguridad a gestionar casos desde la detección hasta la resolución:

  • Alertas: Importar alertas de fuentes externas (SIEM, correo, etc.) para crear casos automáticamente. Las alertas contienen información preliminar sobre eventos de seguridad.
  • Casos: Unidad central de gestión de incidentes. Cada caso contiene observables, tareas y la línea de tiempo de la investigación.
  • Observables: Artefactos extraídos de casos (direcciones IP, dominios, hashes, URLs, etc.) que pueden enriquecerse mediante analizadores de Cortex.
  • Tareas: Elementos de acción asignados a miembros del equipo para avanzar en la investigación. Las tareas pueden rastrearse con actualizaciones de estado.
  • Plantillas de Casos: Estructuras predefinidas para tipos de incidentes comunes para estandarizar los procedimientos de respuesta.
  • Exportar a MISP: Compartir información de casos con MISP para la colaboración de inteligencia de amenazas.

Autenticación

TheHive utiliza autenticación por clave de API. Incluya la clave de API en el encabezado de Authorization.

Encabezado de Authorization: Authorization: Bearer {api_key}

Alertas

POST /api/alert

Crear una alerta

GET /api/alert

Listar todas las alertas

GET /api/alert/{alert_id}

Obtener alerta por ID

POST /api/alert/{alert_id}/case

Promocionar alerta a caso

POST /api/alert/{alert_id}/merge/{case_id}

Fusionar alerta en caso

Gestión de Casos

POST /api/case

Crear un nuevo caso

GET /api/case

Listar todos los casos

GET /api/case/{case_id}

Obtener caso por ID

PATCH /api/case/{case_id}

Actualizar un caso

GET /api/case/_list

Listar plantillas de casos

POST /api/case/_fromTemplate/{template_id}

Crear caso desde plantilla

GET /api/case/{case_id}/customFields

Listar campos personalizados

PATCH /api/case/{case_id}/customFields

Actualizar campos personalizados

PATCH /api/case/{case_id}

Establecer nivel PAP (0-3)

Niveles PAP: 0=Blanco, 1=Verde, 2=Ámbar, 3=Rojo
POST /api/case/{case_id}/export/misp

Compartir caso con MISP

Observables

GET /api/case/{case_id}/observable

Listar observables de un caso

POST /api/case/{case_id}/observable

Añadir observable a un caso

DELETE /api/case/{case_id}/observable/{observable_id}

Eliminar observable

PATCH /api/case/{case_id}/observable/{observable_id}

Marcar observable como IOC

Tareas

GET /api/case/{case_id}/task

Listar tareas de un caso

POST /api/case/{case_id}/task

Crear una tarea

PATCH /api/case/{case_id}/task/{task_id}

Actualizar una tarea

DELETE /api/case/{case_id}/task/{task_id}

Eliminar una tarea

Plantillas de Casos

GET /api/casetemplate/{template_id}

Obtener plantilla de caso

Variables de Entorno

  • THEHIVE_PORT9000
  • THEHIVE_SECRETClave secreta de TheHive

Ejemplos de Pruebas

Usando curl

# Listar Casos
curl -X GET http://localhost:9000/api/case \
  -H "Authorization: Bearer {api_key}"

# Crear Caso
curl -X POST http://localhost:9000/api/case \
  -H "Authorization: Bearer {api_key}" \
  -H "Content-Type: application/json" \
  -d '{"title":"Test Case","description":"Test description","severity":2}'

Usando Python

import requests

api_key = "your_api_key"
headers = {"Authorization": f"Bearer {api_key}"}

# Listar Casos
response = requests.get("http://localhost:9000/api/case", headers=headers)
print(response.json())
