API de Shuffle

Contenedor: soar_shuffle
Puerto: 5001
URL Base: http://localhost:5001/api/v1
Documentación: Documentación de la API de Shuffle

Plataforma SOAR de código abierto para automatización de flujos de trabajo. Shuffle proporciona una API RESTful para gestionar flujos de trabajo, ejecuciones y aplicaciones.

Conceptos y Casos de Uso

Shuffle es una plataforma de automatización de flujos de trabajo que permite a los equipos de seguridad crear y ejecutar playbooks de respuesta automatizada:

  • Flujos de Trabajo: Playbooks de automatización visual que definen una secuencia de acciones a tomar en respuesta a eventos de seguridad. Los flujos de trabajo pueden activarse manual o automáticamente.
  • Aplicaciones: Módulos de integración que conectan Shuffle con herramientas externas (SIEM, firewalls, sistemas de tickets, etc.). Las aplicaciones proporcionan las acciones disponibles en los flujos de trabajo.
  • Triggers: Mecanismos que inician la ejecución del flujo de trabajo (webhooks, tareas programadas, llamadas API, etc.).
  • Ejecuciones: Ejecuciones individuales de un flujo de trabajo. Cada ejecución rastrea el progreso, resultados y cualquier error encontrado.
  • Orborus: El motor de ejecución de flujos de trabajo que ejecuta la lógica real del flujo de trabajo y se comunica con aplicaciones externas.
  • Organizaciones y Usuarios: Soporte multi-tenant para gestionar equipos y control de acceso.

Autenticación

POST /api/v1/users/login

Iniciar sesión para obtener la clave de API

Credenciales por defecto: admin / ChangeMe!

Shuffle utiliza autenticación por clave de API. Incluya la clave de API en el encabezado de Authorization.

Encabezado de Authorization: Authorization: Bearer {api_key}

Flujos de Trabajo

GET /api/v1/workflows

Listar todos los flujos de trabajo

GET /api/v1/workflows/{workflow_id}

Obtener flujo de trabajo por ID

POST /api/v1/workflows

Crear nuevo flujo de trabajo

PUT /api/v1/workflows/{workflow_id}

Guardar flujo de trabajo

DELETE /api/v1/workflows/{workflow_id}

Eliminar flujo de trabajo

POST /api/v1/workflows/{workflow_id}/execute

Ejecutar un flujo de trabajo

POST /api/v1/workflows/{workflow_id}/abort

Abortar ejecución del flujo de trabajo

GET /api/v1/workflows/{workflow_id}/executions

Listar ejecuciones del flujo de trabajo

GET /api/v1/workflows/{workflow_id}/variables

Listar variables del flujo de trabajo

POST /api/v1/workflows/{workflow_id}/variables

Establecer variable del flujo de trabajo

Ejemplos de Pruebas

Usando curl

# Listar Flujos de Trabajo
curl -X GET http://localhost:5001/api/v1/workflows \
  -H "Authorization: Bearer {api_key}"

# Ejecutar Flujo de Trabajo
curl -X POST http://localhost:5001/api/v1/workflows/{id}/execute \
  -H "Authorization: Bearer {api_key}"

Usando Python

import requests

api_key = "your_api_key"
headers = {"Authorization": f"Bearer {api_key}"}

# Listar Flujos de Trabajo
response = requests.get("http://localhost:5001/api/v1/workflows", headers=headers)
print(response.json())
