Puerto: 8082
URL Base: http://localhost:8082
Documentación: Documentación de la API de MISP

Plataforma de intercambio y colaboración de inteligencia de amenazas. MISP proporciona una API RESTful para gestionar eventos, atributos y datos de inteligencia de amenazas.

Conceptos y Casos de Uso

MISP es una plataforma de intercambio de inteligencia de amenazas que permite a las organizaciones colaborar en incidentes de seguridad e indicadores:

  • Eventos: Incidentes de seguridad o reportes de inteligencia de amenazas que contienen indicadores relacionados. Los eventos pueden compartirse con comunidades de confianza.
  • Atributos: Indicadores individuales dentro de un evento (direcciones IP, dominios, hashes, URLs, direcciones de correo, etc.). Los atributos son los datos principales de inteligencia de amenazas.
  • Etiquetas: Etiquetas utilizadas para categorizar y filtrar eventos y atributos. Las etiquetas permiten una identificación rápida de tipos de amenazas, niveles de confianza y TTPs.
  • Listas de Advertencia: Listas de falsos positivos conocidos o indicadores benignos para prevenir la fatiga de alertas y reducir el ruido.
  • Sightings: Reportes de dónde se ha observado un atributo. Los sightings proporcionan contexto sobre la prevalencia de los indicadores.
  • Fuentes y Galaxias: Fuentes externas de inteligencia de amenazas y taxonomías estructuradas para clasificar amenazas.

Autenticación

MISP utiliza autenticación por clave de API. Incluya la clave de API en el encabezado de Authorization.

Encabezado de Authorization: Authorization: {api_key}

Ejemplos de Pruebas

Usando curl

# Listar Eventos
curl -X GET http://localhost:8082/events \
  -H "Authorization: {api_key}"

# Crear Evento
curl -X POST http://localhost:8082/events \
  -H "Authorization: {api_key}" \
  -H "Content-Type: application/json" \
  -d '{"info":"Test Event","threat_level_id":2}'

Usando Python

import requests

api_key = "your_api_key"
headers = {"Authorization": api_key}

# Listar Eventos
response = requests.get("http://localhost:8082/events", headers=headers)
print(response.json())
