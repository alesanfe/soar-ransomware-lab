Redis API

Container: soar_redis
Port: 6379
Protocol: Redis Protocol (RESP)
Documentation: Redis Documentation

In-memory data store and cache. Redis uses its own protocol (RESP) rather than HTTP/REST. Access via redis-cli or client libraries.

Authentication

Redis uses password authentication. Connect with redis-cli and use AUTH command.

Key-Value Operations

SET key value

Set a key-value pair

GET key

Get value by key

DEL key

Delete a key

EXISTS key

Check if key exists

TYPE key

Get key type

EXPIRE key seconds

Set key expiration

TTL key

Get time to live

KEYS pattern

Find keys by pattern
