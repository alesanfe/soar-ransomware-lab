Docker API

Access: Unix Socket (/var/run/docker.sock)
Documentation: Docker Engine API

Container management and orchestration. Docker provides a RESTful API for managing containers, images, networks, and volumes.

Containers

GET /containers/json

List containers

POST /containers/create

Create container

GET /containers/{id}/json

Inspect container

POST /containers/{id}/start

Start container

POST /containers/{id}/stop

Stop container

POST /containers/{id}/restart

Restart container

DELETE /containers/{id}

Delete container

GET /containers/{id}/logs

Get container logs

GET /containers/{id}/stats

Get container stats

POST /containers/{id}/exec

Create exec instance

Images

GET /images/json

List images

POST /images/create

Pull image

DELETE /images/{id}

Delete image

GET /images/{id}/json

Inspect image

POST /images/{id}/tag

Tag image

Networks

GET /networks

List networks

POST /networks/create

Create network

DELETE /networks/{id}

Delete network

POST /networks/{id}/connect

Connect container to network

POST /networks/{id}/disconnect

Disconnect container from network

Volumes

GET /volumes

List volumes

POST /volumes/create

Create volume

DELETE /volumes/{name}

Delete volume

System

GET /info

Get system info

GET /version

Get Docker version

GET /events

Get Docker events

GET /system/df

Get disk usage

Testing Examples

Using curl

# List Containers
curl --unix-socket /var/run/docker.sock http://localhost/containers/json

Using Python

import docker

client = docker.from_env()
containers = client.containers.list()
for c in containers:
    print(c.name, c.status)
