API de Cortex

Contenedor: soar_cortex
Puerto: 9001
URL Base: http://localhost:9001/api
Documentación: Documentación de la API de Cortex

Plataforma de análisis de seguridad para enriquecimiento de observables y automatización. Cortex proporciona una API RESTful para gestionar analizadores, trabajos y respondedores.

Conceptos y Casos de Uso

Cortex es una plataforma de análisis de seguridad que automatiza el enriquecimiento de observables y proporciona capacidades de respuesta automatizada:

  • Analizadores: Herramientas que enriquecen observables con información adicional de fuentes externas (VirusTotal, AbuseIPDB, Shodan, etc.). Cada analizador está diseñado para tipos específicos de observables.
  • Trabajos: Tareas de análisis individuales. Cuando se envía un observable a un analizador, se crea un trabajo para rastrear el progreso y resultados del análisis.
  • Respondedores: Acciones automatizadas que pueden activarse basándose en resultados de análisis (ej. bloquear IPs, crear reglas de firewall, enviar notificaciones).
  • Tipos de Observables: Direcciones IP, dominios, URLs, hashes, direcciones de correo, archivos y otros artefactos que pueden analizarse.
  • Integración con TheHive: Cortex está estrechamente integrado con TheHive. Los observables de casos de TheHive pueden enriquecerse automáticamente por analizadores de Cortex.

Autenticación

Cortex utiliza autenticación por clave de API. Incluya la clave de API en el encabezado de Authorization.

Encabezado de Authorization: Authorization: Bearer {api_key}

Analizadores

GET /api/analyzer

Listar todos los analizadores

GET /api/analyzer/{id}

Obtener analizador por ID

GET /api/analyzer/{analyzer_id}/config

Obtener configuración del analizador

PATCH /api/analyzer/{analyzer_id}/config

Actualizar configuración del analizador

GET /api/analyzer/{analyzer_id}/report/{report_id}

Obtener reporte del analizador

GET /api/analyzer/{analyzer_id}/job

Listar trabajos por analizador

Trabajos

POST /api/analyzer/{analyzer_id}/run

Ejecutar un analizador

GET /api/job

Listar todos los trabajos

GET /api/job/{job_id}

Obtener trabajo por ID

GET /api/job/{job_id}/report

Obtener reporte del trabajo

GET /api/job/{job_id}/wait

Esperar a que termine el trabajo

DELETE /api/job/{job_id}

Eliminar trabajo

Respondedores

GET /api/responder

Listar todos los respondedores

POST /api/responder/{responder_id}/run

Ejecutar un respondedor

Usuarios y Organizaciones

GET /api/organization

Listar organizaciones

GET /api/user/me

Obtener usuario actual

POST /api/user

Crear usuario

PATCH /api/user/{user_id}

Actualizar usuario

DELETE /api/user/{user_id}

Eliminar usuario

GET /api/role

Listar roles

Roles por Defecto: read, analyze, orgAdmin

Verificación de Salud

GET /api/health

Verificar salud de la API

Variables de Entorno

  • CORTEX_PORT9001
  • CORTEX_SECRETClave secreta de Cortex

Ejemplos de Pruebas

Usando curl

# Listar Trabajos
curl -X GET http://localhost:9001/api/job \
  -H "Authorization: Bearer {api_key}"

# Ejecutar Analizador
curl -X POST http://localhost:9001/api/analyzer/{id}/run \
  -H "Authorization: Bearer {api_key}" \
  -H "Content-Type: application/json" \
  -d '{"data":["1.2.3.4"],"dataType":"ip"}'

Usando Python

import requests

api_key = "your_api_key"
headers = {"Authorization": f"Bearer {api_key}"}

# Listar Trabajos
response = requests.get("http://localhost:9001/api/job", headers=headers)
print(response.json())
