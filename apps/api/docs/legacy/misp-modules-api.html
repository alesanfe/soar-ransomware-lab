MISP Modules API

Container: soar_misp_modules
Port: 6666
Base URL: http://localhost:6666
Documentation: MISP Modules GitHub

Expansion, import, and export modules for MISP enrichment. Provides modules for expanding attributes with additional threat intelligence data.

Modules

GET /modules

List all modules

GET /modules/expansion

List expansion modules

GET /modules/export

List export modules

GET /modules/import

List import modules

GET /modules/action

List action modules

GET /modules/{module_name}

Get module info

POST /modules/{module_name}

Run module

GET /modules/{module_name}/health

Get module health

GET /modules/{module_name}/stats

Get module statistics

Environment Variables

  • MISP_MODULES_PORT6666

Testing Examples

Using curl

# List Modules
curl -X GET http://localhost:6666/modules

# Run Module
curl -X POST http://localhost:6666/modules/{name} \
  -H "Content-Type: application/json" \
  -d '{"module":"{name}","data":["1.2.3.4"]}'

Using Python

import requests

# List Modules
response = requests.get("http://localhost:6666/modules")
print(response.json())
