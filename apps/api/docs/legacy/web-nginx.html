Web Management UI

Container: soar_web_management
Port: 8085
Base URL: http://localhost:8085

Web interface for the SOAR Lab Management API. Provides a frontend for managing the lab environment.

Features

  • System metrics dashboard
  • Service status monitoring
  • Test execution interface
  • Backup management
  • Real-time log viewing

Nginx Reverse Proxy

Container: soar_nginx
Ports: 80, 443

Nginx reverse proxy that routes requests to backend services and provides SSL termination.

Exposed Ports

  • Port 80: HTTP reverse proxy (redirects to HTTPS)
  • Port 443: HTTPS reverse proxy (SSL configured)

Other services (Docs site, Shuffle frontend, Web Management UI, MISP, Wazuh Dashboard) are accessed directly on their respective host ports.
