Internal Services

These services run internally within the SOAR lab environment and do not expose HTTP APIs for external consumption.

Shuffle Orborus

Container: soar_orborus
Purpose: Workflow execution scheduler

Orborus is the workflow execution engine for Shuffle. It communicates with the Shuffle backend to execute workflows and handles task scheduling.

Monitoring

docker logs soar_orborus
docker ps | filter soar_orborus

Network Watcher

Container: soar_network_watcher
Purpose: Network traffic monitoring

Network Watcher monitors the Docker network for traffic and events, providing visibility into container communications.

Environment Variables

  • TARGET_NETWORKsoar_soar_net

Monitoring

docker logs soar_network_watcher
docker ps | filter soar_network_watcher

Wazuh Filebeat

Container: soar_filebeat
Purpose: Log shipper to Wazuh

Filebeat collects logs from containers and ships them to Wazuh for analysis and alerting.

Monitoring

docker logs soar_filebeat
docker ps | filter soar_filebeat

Wazuh Indexer

Container: soar_wazuh_indexer
Purpose: OpenSearch for Wazuh
Port: 9200

OpenSearch instance used by Wazuh for storing and indexing security events and alerts.

Monitoring

docker logs soar_wazuh_indexer
docker ps | filter soar_wazuh_indexer

Wazuh Manager

Container: soar_wazuh_manager
Purpose: SIEM engine

Wazuh Manager processes security events, generates alerts, and manages agents.

Monitoring

docker logs soar_wazuh_manager
docker ps | filter soar_wazuh_manager

MISP Modules
