API de Gestión de SOAR Lab

Contenedor: soar_api
Puerto: 8000
URL Base: http://localhost:8000
Documentación: Documentación Auto-Generada de FastAPI

Interfaz de gestión personalizada basada en FastAPI para el entorno del laboratorio SOAR. Proporciona endpoints para análisis, copias de seguridad, pruebas y comunicación por WebSocket.

Conceptos y Casos de Uso

Esta API proporciona capacidades de gestión centralizada para el entorno del Laboratorio SOAR de Ransomware:

  • Autenticación: La autenticación basada en JWT garantiza un acceso seguro a todos los endpoints. Inicia sesión una vez para obtener un token, luego úsalo en todas las solicitudes posteriores.
  • Monitoreo de Salud: Verifica el estado de salud general del entorno del laboratorio y los servicios individuales.
  • Análisis: Obtén métricas sobre el rendimiento del sistema, resultados de pruebas e indicadores clave de rendimiento (KPI) como MTTR (Tiempo Medio de Respuesta) y MTTD (Tiempo Medio de Detección).
  • Gestión de Copias de Seguridad: Crea, restaura y lista copias de seguridad de todo el entorno del laboratorio para recuperación ante desastres.
  • Pruebas: Ejecuta pruebas automatizadas (unitarias, de integración, e2e) para verificar la funcionalidad del laboratorio.
  • Logs por WebSocket: Transmisión de logs en tiempo real para monitorear eventos del sistema.

Autenticación

La API utiliza autenticación basada en tokens JWT. Inicia sesión para obtener un token, luego inclúyelo en el encabezado de Authorization.

POST /auth/login

Inicia sesión para obtener el token JWT

Cuerpo de la Solicitud:
{"username":"admin","password":"WebUIPassword123!@#"}
Encabezado de Authorization: Authorization: Bearer {token}

Ejemplos de Pruebas

Usando curl

# Iniciar sesión
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"WebUIPassword123!@#"}'

# Obtener Métricas
curl -X GET http://localhost:8000/analytics/metrics \
  -H "Authorization: Bearer {token}"

Usando Python

import requests

# Iniciar sesión
response = requests.post("http://localhost:8000/auth/login",
    json={"username":"admin","password":"WebUIPassword123!@#"})
token = response.json()['token']

# Obtener Métricas
headers = {'Authorization': f'Bearer {token}'}
response = requests.get('http://localhost:8000/analytics/metrics', headers=headers)
print(response.json())
