# Glosario de Acrónimos del SOAR Ransomware Lab

Este documento recopila los acrónimos y términos técnicos más relevantes usados en el proyecto y en la documentación de la tesis.

## Acrónimos Técnicos

| Acrónimo | Término completo |
|----------|------------------|
| **API** | Application Programming Interface |
| **CI/CD** | Continuous Integration / Continuous Deployment |
| **CPU** | Central Processing Unit |
| **CSV** | Comma-Separated Values |
| **E2E** | End-to-End (Extremo a Extremo) |
| **EDR** | Endpoint Detection and Response |
| **HTTP** | Hypertext Transfer Protocol |
| **HTTPS** | Hypertext Transfer Protocol Secure |
| **IaaS** | Infrastructure as a Service |
| **IoC** | Indicator of Compromise (Indicador de Compromiso) |
| **IP** | Internet Protocol |
| **JSON** | JavaScript Object Notation |
| **JWT** | JSON Web Token |
| **KPI** | Key Performance Indicator (Indicador Clave de Rendimiento) |
| **MTTR** | Mean Time to Respond (Tiempo Medio de Respuesta) |
| **MFA** | Multi-Factor Authentication |
| **OS** | Operating System |
| **RBAC** | Role-Based Access Control |
| **REST** | Representational State Transfer |
| **SIEM** | Security Information and Event Management |
| **SLA** | Service Level Agreement |
| **SOAR** | Security Orchestration, Automation and Response |
| **SSO** | Single Sign-On |
| **TLS** | Transport Layer Security |
| **TFM** | Trabajo Fin de Máster |
| **UI** | User Interface |
| **URL** | Uniform Resource Locator |
| **VM** | Virtual Machine |
| **WAF** | Web Application Firewall |
| **XDR** | Extended Detection and Response |
